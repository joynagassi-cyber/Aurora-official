    Connexion à un agent

    Le prototype fonctionne sans backend. Dans Aurora, ton agent pourra envoyer les mêmes événements pour piloter l’animation.

    const butterfly = AuroraButterfly.create();

butterfly.dispatch({ type: "run.start" });
butterfly.dispatch({ type: "tool.start", name: "Créer une affiche" });
butterfly.dispatch({ type: "tool.progress", progress: 0.6 });
butterfly.dispatch({ type: "approval.request", label: "Valider le résultat" });
butterfly.dispatch({ type: "done" });
